Computer Architecture Assignments
This repository contains a collection of assignments, projects, and hardware simulations completed as part of the Computer Architecture coursework in the Computer Science and Engineering program at Bangladesh University of Engineering and Technology (BUET). The included materials focus on bridging the gap between high-level software instructions and low-level hardware design, featuring practical implementations of processor architecture and instruction set architectures. As an academic portfolio, this repository demonstrates hands-on experience with MIPS assembly language programming, CPU datapath pipelining, and fundamental microprocessor operations.

A central highlight of the repository is the complete hardware design of a custom 16-bit Floating-Point Adder circuit built entirely using Logisim. This advanced logic circuit accurately executes complex floating-point arithmetic, fully integrating Guard, Round, and Sticky (GRS) rounding mechanisms alongside robust exception handling. Combined with various datapath configurations and assembly optimizations, these projects reflect a rigorous exploration of computer hardware paradigms and provide functional, gate-level insights into how modern processors execute and manage computational workloads.
